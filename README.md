🩺 PFDA_Medical_Device_Performance_Analysis
📊 Automated Tableau Dashboard using Python (Colab) and Tableau Hyper API

This project visualizes trends and insights from the FDA MAUDE (Manufacturer and User Facility Device Experience) dataset.
It uses Python to automate data cleaning and Hyper extract creation, and Tableau to build interactive dashboards for event trend analysis and manufacturer performance evaluation.

🚀 Project Overview
Goal:
To automate the process of cleaning, transforming, and visualizing medical device performance data through a reproducible pipeline connecting Google Colab → Tableau → Tableau Public.

Key Highlights:
Automated .hyper extract generation using the Tableau Hyper API
Seamless integration of Python preprocessing and Tableau visualization
Interactive Tableau dashboard showing trends, manufacturer insights, and event distributions
Easily updatable pipeline via a single Colab run

⚙️ Workflow Overview
1️⃣ Data Cleaning & Preprocessing (Colab Notebook)
Load and preprocess MAUDE data (cleaned_MAUDE_dat.csv)
Handle missing values and convert date columns to datetime objects
Prepare structured output compatible with Tableau

2️⃣ Hyper Extract Generation
Using Tableau’s tableauhyperapi, generate cleaned_MAUDE_data.hyper for Tableau
The Hyper format allows fast querying and data updates
from tableauhyperapi import HyperProcess, Connection, TableDefinition, SqlType, Inserter, Telemetry, CreateMode

3️⃣ Dashboard Creation (Tableau)
Visuals include:
Event Trends: Monthly counts of reported device events
Top Manufacturers: Bar chart of top 10 manufacturers by distinct event count
Event Type Distribution: Donut chart visualizing proportions of deaths, injuries, and malfunctions
These are combined into a single, clean Tableau Dashboard.

4️⃣ Dashboard Update Workflow
Whenever new data is available:
Run the Colab notebook → generates a new .hyper file
In Tableau, choose Data → Replace Data Source → Select new .hyper
Save and publish updated dashboard to Tableau Public

🧠 Key Features
🔁 Automated Extract Generation: Python-based .hyper file creation
⚡ Fast Visual Updates: Replace data source in Tableau without rebuilding visuals
📈 Insightful Analytics: Trends, manufacturer rankings, and event distributions
🧩 Reproducible Workflow: End-to-end process documented in Colab and GitHub
